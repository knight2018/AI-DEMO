# SPEC-005 说明书售后助手

创建日期：2026-10-22。用户已授权按照 specDD 开始执行。生命周期以 status.json 为准。

## 目标与边界

独立 Python FastAPI + 本地网页，使用 LangChain 编排模型请求，不修改评论分析业务。首页显示“仅供演示使用”。以 VIOFO A119 MINI 2 官方英文说明书 V25.12.18 为唯一知识来源，覆盖 Wi-Fi、存储卡与录像、供电三个场景。此版本不训练 YOLO，不凭外观确定型号，不接入订单、退款或自动发送客服消息。

## 输入、过程、输出

1. 输入设备或铭牌图片（PNG/JPEG/WebP，最多 5MB）或人工选择准确型号。图片理解用 AGICTO gemini-3.8-flash，结果仅为候选，必须人工确认。模糊、空白、其他型号不能自动匹配。
2. 确认型号后选择问题类别，输入故障描述。按类别逐个询问必要信息，保存已回答字段，不重复追问。用户可选择“不确定”。
3. 按类别检索官方说明书相关片段。LangChain 调用 AGICTO deepseek-flash，根据问题、已知信息和原文输出结构化排查建议。每条技术建议附 PDF 页码及连续英文原文；引用校验通过后才展示。
4. 输出整体判断（原因只能表述为待核实）、最多三步建议、应观察的结果、无法解决时的转人工条件。用户标记“已解决”或“仍未解决，转人工”，生成可下载的会话摘要，包含输入、回答、建议、引用和处理状态。
5. 会话存 SQLite，刷新可恢复。服务异常保留会话并允许用户明确重试；不切换模型，不生成模拟答案。

## 知识与约束

来源 https://viofotech.com/download/manual/MINI2/A119MINI2EnglishManual.pdf ，来源索引 https://www.viofo.com/pages/manual 。存原 PDF、SHA256、版本、获取日期及按 PDF 页码分栏提取的文本。引用使用 PDF 页码而非印刷页码，避免错位。

不提供拆机、刷机、带电插拔或删除数据操作步骤；格式化等需求转人工，提醒先备份。供电测试须车辆停稳，涉及气囊、电路安装交给专业人员。说明书与用户描述均视为数据，不执行其中夹带的指令。引用存在不等于语义正确，实测需人工复核建议是否被来源支持。

仅绑定本机 127.0.0.1。模型密钥只读 AGI_KEY。网页提示图片和故障文字将发送到 AGICTO，选择无关个人信息的照片。限制请求大小、图片实际格式和像素；错误消息不得泄露密钥。没有跨域开放或外部 URL 下载接口。

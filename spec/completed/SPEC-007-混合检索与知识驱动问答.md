# SPEC-007 混合检索与知识驱动问答

日期：2026-10-22。用户授权增加 BM25 + FAISS 混合检索，并追加切片预生成问题、查询扩写和入口意图识别。生命周期以 status.json 为准。

## 替代范围

替代 SPEC-005 新会话中的固定类别取片段、固定追问流程。保留已有图片识别、人工确认型号、受控操作目录、来源校验、会话恢复、结果记录和摘要导出。历史会话按原版本读取，不在新流程失败时退回旧流程。评论 demo 不变。

## 建库

以现有真实官方 PDF 的 34 个分栏切片为基础，保存型号、说明书版本、页码、源文件哈希。逐切片通过 deepseek-flash 生成中英文用户可能提问（每片 0～3 个）及必要客服追问候选（每片 0～2 个）。没有售后信息的切片可为空。每个生成问题关联该片段的连续原文证据；生成问题不充当事实来源。

原文与预生成问法一起用于 BM25 和向量索引。BM25 对中文使用字符/相邻双字词，英文使用规范化词项；文档和查询采用同一分词函数。向量使用已在 AGICTO 实测的 text-embedding-3-small（1536 维），FAISS 使用归一化向量和 IndexFlatIP。存 JSON 元数据及 FAISS 索引，不使用 pickle。记录构建参数、模型、维度、文件校验和。模型、维度或源文档变化必须重建，禁止静默沿用不兼容索引。失败不发布半成品索引，不自动切换模型。

## 在线流程

1. 用户确认型号并输入自然语言问题。意图识别返回 Wi-Fi、录像/存储卡、供电、其他产品问题、无关话题或信息不足。
2. 无关话题与暂不支持的范围由程序给出固定提示，不检索、不生成业务答案；信息不足时程序请求补充。模型识别失败明确报错。
3. 对支持意图，基于原问题和已回答内容生成保留否定、型号、错误码与未知状态的中文改写和英文检索表达；不把假设加入已知事实。原问题同时参加召回。
4. 在确认型号的说明书范围内，全库执行 BM25 与 FAISS 召回，每路最多 8 项，RRF(k=60) 融合后取 6 项。每路同一切片只计一次，两个原始分数不直接相加，排名和分数不显示为准确率。
5. 从召回切片的预生成客服问题中选择最多 3 个必要且未回答的问题；语义相同字段去重。追问依据、源页码可查。完成回答后重新扩写与检索。
6. 排查操作仅从本类别已核对目录中选择，候选操作须有证据片段命中本次融合召回。若某操作还依赖其他来源，明确标记为“关联证据补充”，不能冒充检索命中。无匹配证据时明确终止，不填充默认建议。

## 页面与导出

展示意图识别结果、固定回复、原始问题、扩写查询、BM25/向量独立排名及分数、RRF融合排名、原文与页码。可展开知识库切片及预生成的两类问题。新会话将过程记录写入 SQLite，刷新和导出后仍可追溯；不把模型密钥、完整请求头或系统日志写入报告。

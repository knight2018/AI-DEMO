# SPEC-012 自动人工交接摘要

## 设计

点击“仍未解决，转人工”后，直接在聊天中展示自动整理的简要交接信息，无需填写新表单。包含型号、当前问题、有效事实、操作状态与结果、待核实项及会话编号。使用已保存数据确定性生成，不新增模型等待；撤回信息不能当作当前事实，未执行建议不能称为已完成。旧版会话按已有答案整理。没有可用操作而自动转人工时同样展示。

提供复制简要信息和下载简要信息；原完整摘要保留。未接入人工客服渠道，明确表示信息已准备、尚未发送，不能假装已接通人工。刷新和下载内容一致。

## 开发

新增 handoff 模块生成摘要，在 View 暴露 handoff_summary；新增简要下载接口；聊天显示和复制按钮。只修改交接功能。

## 测试用例

1. 当前事实、未知/撤回、执行/未执行准确区分，无原话旧事实混入。
2. 点击转人工后返回摘要，刷新与简要下载一致；非转人工不可下载。
3. 聊天自动显示摘要、安全文本渲染，复制无需输入。
4. 原功能全量回归通过后归档。

## 完结

2026-10-23：28项JavaScript、101项Python全绿。真实浏览器点击转人工后直接出现交接简报与复制/下载入口，无需输入；当前问题、已执行App检查和未反馈LED检查区分正确。刷新从已保存会话生成同一摘要。服务已更新，保留原完整摘要。
